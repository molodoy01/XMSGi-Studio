# Security Policy

We take security seriously and appreciate responsible disclosure.

## Reporting a vulnerability

Please do not file public issues for suspected security problems.

Use the repository security reporting flow to submit a private report. If the project does not provide a dedicated security contact in the repository UI, report the issue privately through the maintainers' GitHub Security Advisories channel.

Include:

- the affected component or workflow
- a clear description of the issue
- reproduction steps or a proof of concept
- any suspected impact and severity

## Response expectations

We aim to review and triage reports quickly. If the issue is valid, we will work on a fix and coordinate disclosure in a responsible way.

## Safe usage guidance

- keep Telegram credentials and local app data on the device
- avoid sharing session or cache files publicly
- review any third-party dependencies before release builds

We do not encourage public disclosure before a fix is ready.
