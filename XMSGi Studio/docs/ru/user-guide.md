# Руководство пользователя XMSGi Studio

XMSGi Studio — настольное приложение для планирования и отправки сообщений
в Telegram через ваш личный аккаунт.

Не бот. Не облачный сервис. Не массовая рассылка.

Вы пишете сообщение, выбираете чат, указываете время —
и Telegram отправляет его сам, даже если компьютер выключен.

Приложение работает на Windows, Linux и macOS.
Сессия хранится только на вашем устройстве.

---

## 1. Для кого

XMSGi создан для тех, кто регулярно пишет в Telegram
и хочет делать это вовремя, спокойно и без спешки.

- Владельцы каналов и групп
- Community-менеджеры
- Те, кто ведёт несколько диалогов и не хочет ничего забывать
- Люди, которым важно качество текста, а не скорость клика

Если вам нужен просто «отправить позже» — хватит базового режима.
Если хотите работать с текстом серьёзно — есть Studio.

## 2. Установка

### Системные требования

- Windows 10/11, Linux (x64) или macOS (x64 / Apple Silicon)
- Для запуска из исходников: Node.js 20+ и npm

### Готовые сборки

| Платформа | Формат | Примечание |
|---|---|---|
| Windows | портативный `.exe` | запускается без установки |
| Linux | AppImage, `.deb` | x64 |
| macOS | DMG, ZIP | x64 и arm64 |

Скачать актуальный релиз:
https://github.com/molodoy01/XMSGi-Studio/releases

После первого запуска войдите в Telegram — дальше всё работает локально.

### Запуск из исходников

```bash
npm install
npm run build      # сборка React-рендерера (Vite)
npm run electron   # запуск Electron-оболочки
# либо одной командой:
npm run start
```

Подробнее — в [документации для разработчиков](development.md).

## 3. Первый запуск и вход в Telegram

Вход выполняется по номеру телефона, как в официальном клиенте:

1. **API-данные (при необходимости).**
   В большинстве случаев приложение уже настроено. Если потребуется,
   откройте **Настройки → Расширенные настройки API** и укажите
   `API_ID` и `API_HASH` (получить их можно на https://my.telegram.org).
2. **Номер телефона.** Код подтверждения придёт в Telegram
   (в приложение или SMS — смотрите подсказку `isCodeViaApp`).
3. **Код подтверждения.** Ошибки «код истёк»/«неверный код»/«слишком
   много попыток» показываются человеческим языком.
4. **Пароль двухэтапной аутентификации (2FA)** — если включён
   в вашем аккаунте Telegram.

Состояния входа: `requiresCode` → `requiresPassword` → подключено.

### Варианты выхода

| Действие | Что происходит |
|---|---|
| **Выход (сохранить аккаунт)** | Сессия закрывается, аккаунт остаётся на устройстве — дальше вход одним нажатием «С возвращением» |
| **Забыть аккаунт** | Полностью удаляет сохранённые данные аккаунта с устройства |

## 4. Два режима работы

### Простой режим (Planner)

Быстрый планировщик.
Выбрали чат → написали сообщение → поставили время → готово.
Минимум интерфейса, максимум скорости.

### Studio

Рабочее пространство для тех, кто относится к сообщениям как к контенту.

- Полноценный текстовый редактор с форматированием
  (жирный, курсив, подчёркивание, зачёркивание, ссылки)
- Черновики с цветовой маркировкой
- Шаблоны
- Повторяющиеся расписания
- Удобный выбор чатов и избранное
- История отправок и возможность перепланировать
- Вложения с превью прямо в редакторе
- Инлайн-кнопки (inline keyboard) с предпросмотром

Оба режима используют одну и ту же сессию Telegram
и одну историю. Выбранный режим запоминается между запусками.

## 5. Основные возможности

### Планирование

Сообщение уходит в указанную дату и время.
Telegram хранит его на своих серверах —
компьютер не обязан быть включён.

### Мгновенная отправка

Можно отправить сразу, без ожидания.

### Повторения

Режимы: ежедневно, еженедельно, раз в две недели, ежемесячно,
а также еженедельно по выбранным дням недели.
Заранее задаётся количество повторов — **до 15**.

### Черновики

Сохраняйте незаконченные тексты.
Помечайте цветом. Импортируйте и экспортируйте.
Черновики лежат только у вас на диске
(файлы хранятся в каталоге данных приложения, см.
[Безопасность](security.md#3-что-где-хранится)).
Файлы записываются атомарно, с резервными копиями:
при повреждении основного файла приложение восстановит данные из бэкапа.

### Шаблоны

Часто используемые формулировки — в один клик.
Хранятся локально и доступны в обоих режимах.

### История

Все отправленные и запланированные сообщения в одном месте.
Статусы записей: `scheduled` (запланировано), `sending` (отправляется),
`sent` (отправлено), `failed` (ошибка), `draft` (черновик),
`cancelled` (отменено).

Запланированные сообщения можно **отменить** или **перенести**,
отправленные — удалить из истории, черновики — вернуть в редактор.

### Вложения

Фото и файлы. Превью прямо в редакторе.
Ограничение длины текста: **4096 символов** без вложения,
**1024 символа** с вложением.

### Дополнительно

- **Тихая отправка** (без звука у получателя)
- **Эффекты сообщений** (доступные в Telegram анимации)
- **Инлайн-кнопки** под сообщением
- **Ответы на сообщения** и удаление из «Избранного»

### Лимиты и статусы отправки

- **FloodWait / Slowmode.** При флуд-лимите Telegram приложение
  ставит отправку на паузу и повторяет попытку автоматически;
  в интерфейсе показывается, сколько осталось ждать.
- **Права в чате.** Перед отправкой проверяются права
  (можно ли писать, можно ли планировать).
- **Дубли.** Повторное нажатие «Отправить»/«Запланировать»
  не создаёт вторую копию: операции идемпотентны.

## 6. Приватность и безопасность

XMSGi не требует бота и не передаёт ваши данные
на сторонние серверы.

- Сессия Telegram хранится локально
- Чувствительные данные зашифрованы средствами системы
  (Electron `safeStorage`, где это поддерживается)
- Черновики и вложения лежат в папке приложения на вашем диске
- Никакой аналитики, никакой телеметрии
- Приложение не обращается ни к каким сторонним сервисам

Вы контролируете всё, что происходит с вашим аккаунтом.

Подробности: [Безопасность и приватность](security.md).

## 7. Как это устроено (кратко)

XMSGi использует официальный протокол Telegram (MTProto)
через библиотеку `teleproto`.

Планирование выполняется средствами самого Telegram:
сообщение ставится в очередь на сервере
и отправляется в нужный момент независимо от того,
открыто ли приложение.

Studio — это расширенное рабочее пространство
поверх того же ядра.
Оно не заменяет планировщик, а даёт больше контроля
над текстом, черновиками и повторениями.

Подробнее: [Архитектура](architecture.md).

## 9. Частые вопросы

**Компьютер выключится — сообщение уйдёт?**
Да. Сообщение уже лежит на серверах Telegram в отложенной очереди.

**Что будет, если закрыть приложение сразу после планирования?**
Ничего страшного: подтверждение приходит от Telegram, а история
запланированных хранится локально и восстанавливается при следующем
запуске (прерванные статусы переводятся в «ошибка» с возможностью
повтора).

**Нужен ли бот?**
Нет. Всё работает от имени вашего аккаунта.

**Есть ли подписка или телеметрия?**
Нет и нет.
