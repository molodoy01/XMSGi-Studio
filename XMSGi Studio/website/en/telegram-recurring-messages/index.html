Message scheduling

Schedule recurring Telegram messages

XMSGi Studio can schedule a message for multiple sends: choose its cadence, weekdays, and number of occurrences. Recurrence is finite, with a maximum of 15 sends.

Download XMSGi Studio All scheduler features

Choose an interval and send days

Set the date and time for the first send, then choose a repeat interval:

  • Daily — repeat the message each day.
  • Weekly — choose one or more weekdays.
  • Every two weeks — choose weekdays to repeat every other week.
  • Monthly — repeat on the same calendar date. If a month has no such date, the schedule uses that month's last day.

The occurrence count includes the first send. Choose 1, 3, 5, 10, or 15; for weekly and biweekly schedules, this is the total number of posts, not the number of weeks.

Set up a recurring schedule

  1. 1. Prepare the messageChoose a chat, group, or channel available to your account, then review the text and media in the preview.
  2. 2. Set the first date and timeChoose when the first message should be sent. The app displays your device's time zone.
  3. 3. Configure the repeatSelect an interval, weekdays if needed, and the number of sends. Review the schedule in the queue.

Manage posts after scheduling

Before a message is sent, you can edit, reschedule, or cancel it from the queue. Scheduled messages are stored on Telegram's servers, so your computer does not need to stay on.

XMSGi Studio uses your Telegram account rather than a separate bot. It is a desktop app for Windows, Linux, and macOS.

Frequently asked questions

Can I repeat a message indefinitely?

No. Each schedule has a finite number of sends: 1, 3, 5, 10, or a maximum of 15.

Can I choose multiple weekdays?

Yes. Weekly and biweekly schedules can use one or more selected weekdays.

Can I cancel future sends?

You can edit or cancel a scheduled message from the queue before it is sent.
