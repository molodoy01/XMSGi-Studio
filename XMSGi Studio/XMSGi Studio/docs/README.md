# Документация XMSGi Studio

> Документация сейчас доступна только на русском (RU only).

Официальная документация проекта **XMSGi Studio** — настольного приложения для
планирования и отправки сообщений в Telegram через личный аккаунт.

Версия документации соответствует версии приложения **1.3.6**
(см. [`CHANGELOG.md`](../CHANGELOG.md)).

## Кратко о продукте

- **Не бот и не облако.** XMSGi работает от имени вашего личного аккаунта
  Telegram через официальный протокол MTProto (библиотека `teleproto`).
- **Планирование — на стороне Telegram.** Сообщение попадает в очередь
  серверов Telegram (`scheduleDate`), поэтому компьютер может быть выключен
  в момент отправки.
- **Две связанные рабочие поверхности:** Quick Planner для быстрой отправки,
  планирования и сохранения черновиков; Studio — для полноценной работы
  с редактором, документами, шаблонами и повторами.
- **Светлая и тёмная темы** для всего приложения; Quick Planner показывает
  график подтверждённых отправок за 7 или 30 дней.
- **Общие Posts/History и черновики:** Planner- и Studio-записи видны в одной
  панели. Planner-черновик можно перенести в Studio; коллекции при этом
  сохраняются раздельно.
- **Локальное хранение без телеметрии.** Сессия, черновики, вложения и история
  сохраняются на устройстве; при отправке и планировании сообщение передаётся
  Telegram через ваш аккаунт.
- **Платформы:** Windows (portable `.exe`), Linux (AppImage, `.deb`),
  macOS (DMG, ZIP) — x64 и arm64.
