# Руководство пользователя XMSGi Studio

XMSGi Studio — настольное приложение для создания постов и напоминаний
в Telegram через ваш личный аккаунт.

Не бот. Не облачный сервис. Ваш инструмент для постов и напоминаний.

Вы пишете сообщение, выбираете чат, указываете время —
и Telegram отправляет его сам, даже если компьютер выключен.

Приложение работает на Windows, Linux и macOS.
Сессия хранится только на вашем устройстве.

---

## 1. Для кого

XMSGi создан для тех, кто регулярно пишет в Telegram
и хочет делать это вовремя, спокойно и без спешки.

- Владельцы каналов и групп
- Community-менеджеры
- Те, кто ведёт несколько диалогов и не хочет ничего забывать
- Люди, которым важно качество текста, а не скорость клика

Если вам нужен просто «отправить позже» — хватит базового режима.
Если хотите работать с текстом серьёзно — есть Studio.

## 2. Установка

### Системные требования

- Windows 10/11, Linux (x64) или macOS (x64 / Apple Silicon)
- Для Linux нужен системный keyring (GNOME Keyring, KWallet или совместимый Secret Service), чтобы безопасно сохранять данные Telegram
- Для запуска из исходников: Node.js 20+ и npm

### Готовые сборки

| Платформа | Формат | Примечание |
|---|---|---|
| Windows | портативный `.exe` | запускается без установки |
| Linux | AppImage, `.deb` | x64 |
| macOS | DMG, ZIP (без подписи и notarization) | x64 и arm64 |

Скачать актуальный релиз:
https://github.com/molodoy01/XMSGi-Studio/releases

После первого запуска войдите в Telegram — дальше всё работает локально.

### Первый запуск на macOS

macOS-сборка не подписана и не notarized. В Finder нажмите Control и кликните
по XMSGi Studio, выберите
**Открыть**, затем подтвердите **Открыть** в диалоге. Если запуск всё ещё заблокирован, откройте **Системные настройки →
Конфиденциальность и безопасность → Всё равно открыть**. Обходите предупреждение
только для приложения, скачанного с официальной страницы релизов.

### Запуск из исходников

```bash
npm install
npm run build      # сборка React-рендерера (Vite)
npm run electron   # запуск Electron-оболочки
```

Для разработки с Vite и Electron используйте `npm run dev:electron`.

Подробнее — в [документации для разработчиков](development.md).

## 3. Первый запуск и вход в Telegram

Вход выполняется по номеру телефона, как в официальном клиенте:

1. **API-данные (при необходимости).**
   В большинстве случаев приложение уже настроено. Если потребуется,
   откройте **Настройки → Расширенные настройки API** и укажите
   `API_ID` и `API_HASH` (получить их можно на https://my.telegram.org).
2. **Номер телефона.** Код подтверждения придёт в Telegram
   (в приложение или SMS — смотрите подсказку `isCodeViaApp`).
3. **Код подтверждения.** Ошибки «код истёк»/«неверный код»/«слишком
   много попыток» показываются человеческим языком.
4. **Пароль двухэтапной аутентификации (2FA)** — если включён
   в вашем аккаунте Telegram.

Состояния входа: `requiresCode` → `requiresPassword` → подключено.

### Варианты выхода

| Действие | Что происходит |
|---|---|
| **Выход (сохранить аккаунт)** | Сессия закрывается, аккаунт остаётся на устройстве — дальше вход одним нажатием «С возвращением» |
| **Забыть аккаунт** | Полностью удаляет сохранённые данные аккаунта с устройства |

## 4. Quick Planner и Studio

### Quick Planner

Быстрый экран для трёх действий: отправить сообщение сейчас, запланировать
его в Telegram или сохранить как черновик. Для отправки и планирования нужен
подключённый Telegram и выбранный чат. Запланированное сообщение попадает
в очередь Telegram и не зависит от того, включён ли компьютер в момент отправки.

Текущий текст, форматирование и вложения автоматически сохраняются локально.
Действие **Draft** добавляет отдельную запись в коллекцию Planner-черновиков;
их можно закреплять и удалять. Выбранные черновики можно перенести в Studio.
Для сохранения черновика чат не нужен; для отправки и планирования необходимы
подключённый аккаунт и выбранный чат.

В правой части Планера отображается активность с графиком подтверждённых
отправок. Переключатель позволяет посмотреть последние **7** или **30 дней**;
график учитывает только сообщения, отправку которых подтвердил Telegram.

### Studio

Расширенное рабочее пространство для подготовки контента: форматирование,
вложения с превью, шаблоны, повторяющиеся расписания, цветные
документы и история версий.

Текущий текст Planner можно открыть в Studio вместе с форматированием и
вложениями. Несколько сохранённых Planner-черновиков можно передать в Studio
одним действием.

### Общие действия и границы

- Обе поверхности используют одну сессию Telegram и общую панель Posts/History.
- В Posts/History видны очереди и результаты отправки, текущий и сохранённые
  Planner-черновики, а также сохранённые Studio-документы.
- Planner-черновик можно передать в Studio. Документ Studio можно открыть
  в Studio из общей панели.
- Коллекции доступны из общего интерфейса, но хранятся раздельно: Planner —
  в локальном хранилище renderer, Studio — в файловом draft store приложения.

Выбранная рабочая поверхность запоминается между запусками.

### Светлая и тёмная тема

Откройте **Настройки → Тема приложения** и выберите светлую или тёмную тему.
Настройка применяется ко всему приложению и сохраняется на этом устройстве.

## 5. Основные возможности

### Планирование

Сообщение уходит в указанную дату и время.
Telegram хранит его на своих серверах —
компьютер не обязан быть включён.

### Мгновенная отправка

Можно отправить сразу, без ожидания.

### Повторения

Режимы: ежедневно, еженедельно, раз в две недели, ежемесячно,
а также еженедельно по выбранным дням недели.
Заранее задаётся количество повторов — **до 15**.

### Черновики

В Quick Planner текущий текст сохраняется автоматически, а действие **Draft**
добавляет отдельную запись в коллекцию. В Studio текущий рабочий документ
автосохраняется; сохранённые документы можно назвать, пометить цветом,
редактировать, импортировать и экспортировать.

Черновики обеих поверхностей доступны в общей панели Posts/History. Planner-
черновик можно перенести в Studio; Studio-документы управляются в Studio.
Хранилища раздельные: Planner использует localStorage,
Studio — локальный файловый draft store с атомарной записью и резервными копиями.
Подробности: [Безопасность](security.md#3-что-где-хранится).

### Шаблоны

Часто используемые формулировки — в один клик.
Хранятся локально и доступны в Studio.

### История

Отправленные и запланированные сообщения Planner и Studio доступны в общей
панели Posts/History. Там же видны сохранённые черновики обеих поверхностей.
Статусы записей: `scheduled` (запланировано), `sending` (отправляется),
`sent` (отправлено), `failed` (ошибка), `draft` (черновик),
`cancelled` (отменено).

Неудачные попытки отправки остаются в истории со статусом «ошибка».
В записи можно посмотреть причину последней неудачной попытки и повторить
отправку или планирование, если действие доступно.

Запланированные сообщения можно **отменить** или **перенести**,
отправленные — удалить из истории. Planner-черновик можно перенести в Studio;
Studio-документ открывается в рабочем пространстве.

### Вложения

Фото и файлы. Превью прямо в редакторе.
Ограничение длины текста: **4096 символов** без вложения,
**1024 символа** с вложением.

### Дополнительно

- **Тихая отправка** (без звука у получателя)
- **Эффекты сообщений** (доступные в Telegram анимации)
- **Ответы на сообщения** и удаление из «Избранного»

### Лимиты и статусы отправки

- **FloodWait / Slowmode.** При флуд-лимите Telegram приложение
  ставит отправку на паузу и повторяет попытку автоматически;
  в интерфейсе показывается, сколько осталось ждать.
- **Права в чате.** Перед отправкой проверяются права
  (можно ли писать, можно ли планировать).
- **Дубли.** Повторное нажатие «Отправить»/«Запланировать»
  не создаёт вторую копию: операции идемпотентны.

## 6. Приватность и безопасность

XMSGi не требует бота и не использует собственный облачный backend или
аналитику. При отправке или планировании текст и вложения передаются Telegram,
поскольку сообщение доставляется через ваш аккаунт.

- Сессия Telegram хранится локально
- Чувствительные данные зашифрованы средствами системы
  (Electron `safeStorage`, где это поддерживается)
- Planner-черновики хранятся в локальном хранилище приложения; Studio-черновики
  и их постоянные копии вложений — в каталоге данных приложения
- Никакой аналитики, никакой телеметрии
- Сетевое соединение используется для Telegram и загрузки/отправки медиа

Вы контролируете всё, что происходит с вашим аккаунтом.

Подробности: [Безопасность и приватность](security.md).

## 7. Как это устроено (кратко)

XMSGi использует официальный протокол Telegram (MTProto)
через библиотеку `teleproto`.

Планирование выполняется средствами самого Telegram:
сообщение ставится в очередь на сервере
и отправляется в нужный момент независимо от того,
открыто ли приложение.

Quick Planner и Studio — связанные поверхности одного приложения. Они используют
общий Telegram runtime и Posts/History; Planner-черновики можно передавать в
Studio. Studio при этом хранит собственные документы и историю версий отдельно.

Подробнее: [Архитектура](architecture.md).

## 9. Частые вопросы

**Компьютер выключится — сообщение уйдёт?**
Да. Сообщение уже лежит на серверах Telegram в отложенной очереди.

**Что будет, если закрыть приложение сразу после планирования?**
Ничего страшного: подтверждение приходит от Telegram, а история
запланированных хранится локально и восстанавливается при следующем
запуске (прерванные статусы переводятся в «ошибка» с возможностью
повтора).

**Нужен ли бот?**
Нет. Всё работает от имени вашего аккаунта.

**Есть ли подписка или телеметрия?**
Нет и нет.
